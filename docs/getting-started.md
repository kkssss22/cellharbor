# 开始使用格子助手

## 先试一遍，不用安装

打开[浏览器演示](https://kkssss22.github.io/cellharbor/)。页面中的表格是虚构样例，可以直接编辑，也可以粘贴从 Excel 复制的数据。

第一次建议尝试“去首尾空格”：

1. 在示例表格中输入带首尾空格的名字。
2. 搜索或选择相应工具，阅读用途说明。
3. 查看预览中的原值和修改结果。
4. 应用修改，再试试单步撤销。

浏览器演示不会读取你打开的 Excel，也不支持直接导入 `.xlsx`。粘贴多行多列内容时，使用 Excel 复制得到的制表符分隔文本。

## 把一段文字排成表格

进入“粘贴排表”，按步骤设置内容、分隔方式和行列布局。

例如，把 `张三,销售,李四,财务,王五,运营` 粘贴进向导：单元格分隔符选逗号，列数设为 2，选择按行填充，结果是三行两列。选择按列填充时，数据会先从上到下填满一列，再填下一列；预览会展示实际顺序。

分隔符可以是一个符号，也可以是完整的自定义文字。换行使用换行选项或 `\n`，制表符使用对应选项或 `\t`。如果原文还用另一个符号区分每行，可同时指定行分隔符。分隔符按字面含义处理，不按正则表达式解释。

只指定列数时，向导按内容推算所需行数；只指定行数时，推算列数。同时指定行和列时，容量固定：不足补空白单元格，超出则提示调整容量，不会自动丢弃多出的数据。

核对预览后再确认输出。在 Excel 中会创建新工作表；在浏览器演示中会替换当前演示表格。这个向导不读取 Excel 文件，也不保证解释带引号或跨行字段的标准 CSV。

## 在真实 Excel 中使用

格子助手是 Office.js 任务窗格加载项。仓库提供 XML 清单，用于测试侧载；目前没有商店安装入口或一键安装程序。清单只描述加载项，实际页面通过 HTTPS 加载。

先保存 [manifest.xml](https://kkssss22.github.io/cellharbor/manifest.xml) 到本机。如果浏览器显示 XML 文本，可使用“另存为”，保留 `.xml` 扩展名。

### Excel 网页版

1. 在 Excel 网页版打开一份工作簿。
2. 进入“开始 → 加载项”，打开更多设置。
3. 在 Office 加载项对话框选择“上传我的加载项”。
4. 选择下载的 `manifest.xml` 并上传，检查格子助手窗格是否出现。

菜单名称可能随语言和版本变化；以 [Microsoft 官方侧载说明](https://learn.microsoft.com/en-us/office/dev/add-ins/testing/sideload-office-add-ins-for-testing)为准。没有上传入口时，账号或组织可能未开放自定义加载项，需要咨询管理员。换浏览器或清除浏览器缓存后，可能需要重新侧载。

### Windows 桌面 Excel

微软提供通过“受信任加载项目录 / 共享文件夹”测试 XML 加载项的流程。将清单放入自己或管理员设置的专用共享目录，按官方步骤登记目录、重启 Excel，再从加载项对话框的共享文件夹入口添加。共享目录方式用于测试，不是正式生产部署渠道。请按 [Microsoft Windows 侧载说明](https://learn.microsoft.com/en-us/office/dev/add-ins/testing/create-a-network-shared-folder-catalog-for-task-pane-and-content-add-ins)操作。

企业批量分发需要由组织管理适合的加载项部署方式。本项目不会自动修改你的 Excel 信任设置、注册表或组织策略。

### 开发者测试

对于部署在远程 HTTPS 站点的加载项，微软也提供 `office-addin-debugging` 工具。它会登记测试加载项；结束时需要使用它的停止命令清理测试登记，而不仅仅是关掉 Excel。具体操作见[官方远程测试说明](https://learn.microsoft.com/en-us/office/dev/add-ins/testing/test-debug-non-local-server)。

本项目的 `npm run dev` 仅启动浏览器演示。修改部署地址时，应同步修改清单中的资源 URL，并重新验证清单；不能把本地 HTTP 演示地址当作已配置好证书的 Excel 开发环境。

## 日常操作

1. 在 Excel 中选中一个连续的矩形区域。尽量选择实际数据，不要直接选择整张工作表。
2. 根据选区设置“首行是标题”，避免把标题当普通数据处理。
3. 搜索一个工具，查看说明并设置参数。
4. 预览结果，核对原值、目标值、跳过项和输出位置。
5. 确认无误后应用。若选区或单元格已经发生变化，请重新读取并预览。

“检查”类工具用于发现问题；发现空白或重复并不意味着它们一定错误。“提取 / 整理”类工具把结果写到新工作表，**只包含值，不保留原公式和格式**。

## 常见问题

**为什么公式没有被清理？**

原地转换有意跳过公式。若需要处理计算结果，可先明确复制为值，再对副本操作。

**为什么 `00123` 没变成数字？**

它可能是编号。数字转换会保护前导零和超出安全精度的长数字，避免改变其含义。已经被 Excel 舍入或截断的数字无法从现有单元格恢复。

**为什么撤销被拒绝？**

工具只撤销当前会话最近一次原地转换，并先核对目标值。如果你或协作者已经改过那些单元格，工具不会覆盖新内容。新表输出不由此按钮撤销。关闭窗格后不要依赖这份临时撤销记录；浏览器演示刷新后会重置。

**为什么新表没有颜色、公式或批注？**

新表是提取结果，不是原工作表的完整复制；这里只写入值。原表仍然保留。

**为什么加载项打不开？**

先确认部署页面和清单中的 HTTPS 地址可访问，再检查 Excel 是否允许自定义加载项及当前主机是否满足所需 API。Office 模式需要访问 Microsoft Office.js CDN。浏览器演示可用，不等于所有 Excel 版本都已兼容。

## 明确指定何时换行或换列

展开“我的数据有指定的换行 / 换列标记”，填写换组分隔符，然后选择“开始下一行”或“开始下一列”。例如 `A,B|C,D`，单元格分隔符为逗号、换组分隔符为竖线：换行得到 `A B / C D`，换列得到 `A C / B D`。有换组标记时，自动横向/纵向填充会停用，以保留分组关系。

网页工具箱底部的“复制当前全表”和“下载当前 TSV”包含完整数据，不受可见预览行数限制。生成结果后可“返回来源表”；刷新页面会清空本次会话数据，请及时导出。所有导出的文本项带 Excel 文本保护前缀，以保留编号并阻止公式注入；其他软件可能显示这个前缀。
