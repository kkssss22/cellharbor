# 隐私与数据处理

CellHarbor 不提供账号系统、工作簿上传接口、AI 服务或分析追踪。工具逻辑在浏览器或 Excel 加载项窗格中执行。

## 浏览器演示

- 页面提供虚构示例表格，用户可以编辑或粘贴数据。
- 表格内容用于当前页面的预览、处理和撤销。
- 演示内容和撤销记录仅保存在当前页面内存，不写入 `localStorage`；刷新页面会重置。
- 演示模式不连接本地 Excel，不读取工作簿文件，也不加载 Office.js。
- 页面代码由托管站点提供；访问站点仍会产生普通的网页请求。

## Excel 模式

- 通过 Office.js 读取选中的区域，并在用户应用操作时写回预览涉及的单元格，或生成一个包含结果值的新工作表。
- 选区内容和撤销所需的原值在加载项内参与计算。应用没有将这些内容提交到远程服务的代码路径。
- Office.js 从 Microsoft 官方 CDN 加载。加载脚本需要网络请求；这不等于 CellHarbor 把选区数据上传给自己的服务器。
- GitHub Pages 提供应用文件。GitHub、Microsoft 和组织自身服务可能按各自规则处理访问日志及其他服务数据，本项目不能代表这些服务承诺“完全没有网络通信”。

Excel 工作簿是否保存到 OneDrive、SharePoint 或本地，由 Excel 与你的组织设置决定；CellHarbor 不改变这些保存或同步设置。

## 使用与撤销

对原数据的修改需要先预览再应用。原地转换跳过公式。单步撤销只针对当前会话最近一次原地转换，并检查单元格是否已被后续修改；它不是备份，也不是完整工作簿恢复工具，不负责撤销新表输出。

提取和整理结果写入新表时仅包含值。输出中可能仍然包含原数据的敏感内容，分享结果表格前应按自己的工作要求检查。

## 报告问题

请不要把真实客户、员工、账号、财务或其他敏感表格发到公开 issue。使用虚构样例说明操作步骤通常足以复现问题。
