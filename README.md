从网页复制来的名字带着空格，数字存成了文本，编号超过了 Excel 的精度范围，表格里还有空行和重复项……这些小问题，不必每次都搜索公式。

格子助手先帮你把混在一起的数据排成表格，再把常用操作变成看得懂的工具。每项都有用途说明，先展示结果，再由你决定应用。真实 Excel 中以侧边栏加载项运行；浏览器演示提供一张可编辑的示例表格，方便先试用。

## 粘贴数据，按你想要的行列排好

从消息、网页、文本文件复制一大段数据，交给“粘贴排表”向导：

1. **粘贴内容：** 不需要先整理成标准表格。
2. **选分隔方式：** 单元格可按逗号、空格、换行、制表符或自定义文字分开；也可以另外指定换组分隔符，并选择遇到标记时开始下一行或下一列。
3. **设行列：** 指定列数、行数，或同时指定两者；选择先填满一行还是先填满一列。
4. **预览并输出：** 不足的位置补空白；数据超过指定容量时明确报错，不会悄悄截掉内容。

真实 Excel 中始终输出到新工作表。浏览器演示中，点击确认后在演示区显示结果，可点击“返回来源表”找回上一张来源表。向导按文字分隔，不会把分隔符当正则表达式，也不是处理所有 CSV 引号规则的文件导入器。

## 能做什么

| 想完成的事 | 工具示例 |
| --- | --- |
| 清理复制来的内容 | 去首尾空格、去全部空格、合并连续空格、清除不可见字符、全角转半角 |
| 统一文本 | 英文大写/小写/单词首字母大写、查找替换 |
| 整理数字 | 文本转数字、数字转文本、百分数字符串转数值、四舍五入、绝对值、正负反转 |
| 补齐数据 | 向下填充、空白填零 |
| 找出问题 | 重复内容、空白单元格、数字型文本、长编号、列内类型不一致 |
| 生成新结果 | 简单统计、提取不重复行、按分隔符拆列、行列互换、去掉空行、添加序号 |

搜索工具名或按分类浏览即可使用，不需要编写公式。另有 8 个常用公式模板，配合说明帮助你了解和复制公式。

## 两种使用方式

**先在浏览器试用：** 打开[在线演示](https://kkssss22.github.io/cellharbor/)，编辑示例单元格，或粘贴从 Excel 复制的制表符分隔数据（单元格分隔符设为 `\t`、换组分隔符设为 `\n`，并选择开始下一行）。演示不会连接你的本地 Excel，也不提供 `.xlsx` 文件导入。

**在 Excel 中使用：** 下载 [manifest.xml](https://kkssss22.github.io/cellharbor/manifest.xml)，按[安装说明](docs/getting-started.md)测试侧载。在 Excel 里选中一个连续区域，再从格子助手侧边栏操作。组织策略、Excel 版本和加载项权限会影响可用性。

这是 **Office.js Excel 加载项**，不是 Chrome 扩展、VBA 宏或已经上架商店的安装包。当前仓库提供源代码、网页演示和可供侧载的 XML 清单。

## 修改前看得见，修改后有边界

- **先预览：** 检查操作列出的原值、结果和影响范围，再应用。
- **保护公式：** 原地转换跳过公式单元格，避免把计算逻辑直接覆盖成结果。
- **单步撤销：** 对最近一次原地转换，可在当前会话中撤销；如果目标单元格已被改动，撤销会拒绝覆盖新的内容。新表输出不在此撤销范围内；它也不是完整的 Excel 撤销历史。
- **输出另存：** 整理和提取工具把结果写入新工作表，输出为**值**，不复制公式、格式、图表或批注。
- **编号谨慎转换：** 文本转数字保留前导零编号和可能超出安全精度的长数字。已经被 Excel 截断的编号，工具无法恢复。

批量操作建议先用一小块区域确认效果。“首行是标题”会影响工具如何处理选区，请按实际表格设置。

## 数据在哪里？

表格处理在加载项或浏览器本地执行，应用没有数据上传接口、AI 服务或分析追踪。Excel 模式需要从 Microsoft 官方 CDN 加载 Office.js；网页文件由 GitHub Pages 提供。Excel 本身的保存、同步和组织管理仍遵循你现有的 Microsoft 设置。详见[隐私说明](docs/privacy.md)。

## 本地开发

需要 Node.js 22 或更高版本：

```sh
git clone https://github.com/kkssss22/cellharbor.git
cd cellharbor
npm run dev
```

打开 **http://localhost:4173** 使用浏览器演示。项目使用原生 JavaScript 模块，无需安装第三方运行或构建依赖。

```sh
npm test
npm run build
```

构建输出为 `dist/`。本地 HTTP 演示服务器不会自动把加载项安装进 Excel；清单默认指向已部署的 HTTPS 页面。开发工具清单验证可使用微软的 `npx office-addin-manifest validate manifest.xml`，详见[官方文档](https://learn.microsoft.com/en-us/office/dev/add-ins/testing/troubleshoot-manifest)。

## 验证范围

已通过 Node 自动化检查和浏览器交互验证：排表方向、边界、溢出提示、工具预览、修改、撤销与窄屏布局。Office 桥接有模拟接口测试，尚未在真实 Excel 主机中完成侧载验收；不同版本的表现仍需按[安装说明](docs/getting-started.md)用示例数据验证。
